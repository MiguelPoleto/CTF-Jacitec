# Challenge 02

Nome: Mapa do site
Dificuldade: Fácil
Pontos: 10

Flag: JACITEC{robots_are_not_for_kids}

Conceito: robots.txt / descoberta de conteúdo

Como resolver:
1. Analise a estrutura do site e veja quais caminhos públicos podem existir sem aparecer na interface principal.
2. Use um navegador ou um comando como curl para testar URLs simples, em especial arquivos de descoberta e exploração.
3. O arquivo robots.txt é um ponto clássico: ele revela a intenção do site e pode apontar para caminhos não listados.
4. A flag pode estar em um endpoint ou rota não visível pelo front-end, mas acessível por URL direta.

Ferramentas úteis:
- curl
- navegador com Network
- inspeção de endpoints e robots.txt

Dica 1: Procure por arquivos de descoberta do site.
Dica 2: O navegador não mostra tudo automaticamente.
Dica 3: Revise o arquivo de robots e caminhos escondidos.
