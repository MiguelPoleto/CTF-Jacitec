# Challenge 02

Nome: Mapa do site
Dificuldade: Fácil
Peso base: 5 pontos

Flag: `JACITEC{map_the_hidden_routes}`

Conceito: sitemap / descoberta de conteúdo

## Como resolver

1. Abra **Guias de viagem** no menu do Wayfarer e clique em **Mapa do site do portal**.
2. O sitemap lista a URL completa de uma página auxiliar fora da navegação principal.
3. Acesse essa URL (`/lab/2/files/report`). O relatório contém a flag.
4. Copie a flag exatamente como aparece.

Ferramentas úteis:
- Navegador
- Sitemap XML do laboratório

Dicas:
1. Procure o link **Mapa do site do portal** na página de Guias de viagem.
2. O mapa lista páginas auxiliares que não aparecem no menu principal.
3. Acesse `/lab/2/files/report`; a flag está no relatório.
