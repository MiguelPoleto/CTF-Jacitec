# Challenge 04

Nome: Arquivo de frontend
Dificuldade: Fácil
Pontos: 10

Flag: JACITEC{js_holds_the_truth}

Conceito: DevTools / JavaScript / frontend

Como resolver:
1. Abra o DevTools e vá para a aba "Sources" ou "Console".
2. Revise os scripts carregados pela webpage. Muitas vezes a pista está em um bloco JS ou em uma string que não aparece no HTML final.
3. Procure por textos legíveis, comentários, arrays, objetos ou constantes que contenham a senha ou a flag.
4. O navegador pode não mostrar os dados úteis na página visível, mas o código-fonte do frontend tem tudo isso.

Ferramentas úteis:
- DevTools
- Console do navegador
- busca por palavras-chave como "flag", "secret", "token", "JACITEC"

Dica 1: Abra o console e veja os scripts carregados.
Dica 2: O código do JavaScript pode revelar strings úteis.
Dica 3: Procure por valores que parecem pistas ou flags.
