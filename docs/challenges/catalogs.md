# Catálogos de desafios

O JACITEC CTF possui três listas de desafios para alternar entre edições.

- Lista 1: fundamentos e os laboratórios clássicos.
- Lista 2: cenários alternativos de descoberta, análise HTTP e validação de entradas.
- Lista 3: uma terceira coleção para reduzir repetição para participantes recorrentes.

Cada lista contém ao menos quatro desafios fáceis, quatro médios e quatro difíceis; a primeira possui laboratórios extras para ampliar a rotação. No painel administrativo, escolha uma lista e informe quantos desafios de cada dificuldade serão usados. A soma deve ser de 1 a 8. A plataforma sorteia as atividades, embaralha sua ordem e grava a seleção junto ao CTF.

Isso significa que o administrador controla o nível da edição sem escolher nem antecipar quais desafios individuais serão apresentados. Depois de sorteado, um desafio deixa de estar disponível para uma nova edição da mesma lista: o painel mostra a quantidade inédita restante e bloqueia uma composição que causaria repetição. O histórico sempre mostra os resultados da seleção original.

As atividades são educacionais e exclusivas do ambiente isolado. Quando um desafio indicar análise HTTP, o participante deve usar DevTools, `curl` ou Burp Suite Community; não há necessidade nem autorização para testar alvos externos.
